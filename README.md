# Careousel

Cross-clinic appointment and intelligent waitlist platform. Synthetic demo foundation; portals and backend workflows are not implemented yet.

Use Node 24.19.0 and npm 11.9.0. Run `npm ci`, then `npm run dev`. See [architecture](docs/architecture.md) for setup, directory ownership, design system and checks; [API contracts](docs/api-contracts.md) for shared transport/state rules. [PRD](PRD.md) defines product acceptance; [TASKS](TASKS.md) records remaining milestones.

Database schema belongs to PR #2. Integrate it through review; this branch contains no competing schema. Application implementation is authorized; public deployment needs separate approval.
